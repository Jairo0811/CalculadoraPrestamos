Soporte y sugerencias

Para reportar errores de la calculadora, problemas de accesibilidad o proponer mejoras, utiliza el registro de incidencias del repositorio oficial. Puedes consultar el seguimiento de cada reporte.

Abrir una incidencia en GitHub

Aviso: las incidencias de GitHub son públicas. No publiques cédulas, números de cuenta, correos privados, contraseñas ni datos confidenciales.

Privacidad y datos personales

El simulador público no requiere registro. Si has guardado datos personales opcionales en una simulación, puedes eliminar su historial local desde la aplicación o la configuración del navegador.

No envíes información personal por GitHub Issues. El sitio no dispone todavía de un formulario privado de contacto ni de una bandeja de atención para datos sensibles. Antes de habilitar las cuentas se incorporará un canal privado para estas solicitudes.

Leer la Política de Privacidad

Sobre los resultados financieros

LoanCalc RD no es un banco ni una entidad de préstamos. Si tienes preguntas sobre una tasa, comisiones, seguros o la aprobación de un crédito, consulta directamente a la institución financiera correspondiente.
